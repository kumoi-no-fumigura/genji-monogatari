## 作品について

光源氏の生涯と、その子薫・孫の匂宮の世代までを描く54帖の長編物語。ここの本文は池田亀鑑『校異源氏物語』の底本（主に大島本）の本文で、諸本の異文（校異）は除いている。桐壺・夢浮橋など、帖によって底本が異なる。

## 本文の作り方

国立国会図書館の全文テキスト（OCR）から作品の範囲を切り出し、原本のページごとに段落に分け、ページの先頭や末尾にある書名（柱）を除きました。それ以外は手を加えていません。旧字の誤認識・ルビ・割注などがそのまま混じっています。

## ファイル

| パス | 中身 |
|---|---|
| `honbun/` | 本文。1 行が 1 段落で、`段落ID<TAB>本文` の形です。原本の行の切れ目は ⏎ で示しています（⏎ は改行の印で、本文の字ではありません）。50段落ごとにファイルを分けています（37ファイル）。 |
| `uta.tsv` | 作中歌の一覧（番号・段落ID・本文・読み・詠み手・種別・原本のコマ）。 |
| `genji.json` | 本文・底本・作品の説明・作中歌のデータをまとめた JSON（訳は入れず、`yaku/` だけに置いています）。段落ごとに原本のコマ番号があります。 |

段落ID（例: `genji-0001`）は、本文を直しても変わりません。原本の画像は、底本のリンクからコマ番号で見られます。

## 誤りを見つけたら


- **Issue で知らせる**：[「本文の誤り」の Issue を作る](https://github.com/kumoi-no-fumigura/genji-monogatari/issues/new?template=teisei.yml)。段落ID・いまの本文・直した本文・根拠を書いてください。
- **直接直す**：`honbun/` の該当行を直して Pull Request を送ってください。段落IDと行の順番は変えないでください。

受け取った修正は、原本の画像と照らして確かめてから取り込みます。
